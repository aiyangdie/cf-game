# 产品路线图 Roadmap

> 目标：开源、可部署、可协作，持续迭代成完整网页 CF 类射击游戏。

## 已完成 ✅（v1.0.0）

- [x] 第一人称射击 + Three.js
- [x] GitHub Pages 在线部署
- [x] 三武器切换（AK / 沙鹰 / 军刀）
- [x] 道具：补血、补弹
- [x] 爆头提示与统计
- [x] 掩体碰撞、波次敌人
- [x] Release 打包下载
- [x] 可选访问密码门（静态站）

## v1.1 — 战斗增强（欢迎 PR）

- [ ] **音效**：枪声、换弹、爆头、拾取、环境音
- [ ] **手雷**：G 键投掷、范围伤害、冷却
- [ ] 击杀反馈优化（飘字、连杀）

- [ ] **狙击枪**：开镜（右键）、高伤害、慢射速

## v1.3 — 地图

- [ ] **地图切换**：训练场 / 仓库 / 沙漠
