# 产品路线图 Roadmap

> 目标：开源、可部署、可协作，持续迭代成完整网页 CF 类射击游戏。

## 已完成 ✅（截至 v1.0.5）

- [x] 第一人称射击 + Three.js
- [x] GitHub Pages 在线部署 + Release 打包下载
- [x] 三武器切换（AK / 沙鹰 / 军刀）
- [x] 道具：补血、补弹、击杀掉落
- [x] 爆头提示与统计
- [x] 掩体碰撞、波次敌人、屏幕外敌人箭头
- [x] 可选访问密码门（静态站）
- [x] **音效**（`audio.js`：枪声、换弹、爆头、脚步等，M 静音）
- [x] **暂停**（ESC / P）
- [x] 子弹轨迹、弹着点火花、准星后坐
- [x] **移动**：跳跃、Shift+W 冲刺、后退减速、head bob
- [x] Shift 按键卡住修复（失焦/暂停时清空按键）
- [x] 主菜单版本号 / build 号、资源缓存 bust

## v1.1 — 战斗增强（欢迎 PR）
